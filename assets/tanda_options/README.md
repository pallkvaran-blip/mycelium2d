# TANDA can label — SVG

`tanda-label.svg` — a vector rebuild of the mango sparkling-juice can label, generated by
`scripts/gen_tanda_label.py`. Regenerate with `python3 scripts/gen_tanda_label.py`.

## What this is, and is not

The source was a photographic can **mockup**, not flat artwork, so nothing here is traced.
Every element is redrawn: it is a clean, editable interpretation at print quality, not a
pixel copy. Expect differences in the illustration's detail and in the letterforms.

## Sizing

The artwork is the **front panel**, portrait, `viewBox="0 0 600 1600"` — matching the face
visible on the mockup. Being vector it scales to any size with no loss.

For a **full wrap** on a 330 ml sleek can you need a wider canvas: the can is 58.1 mm in
diameter, so the wrap is about **182 mm** around (π × 58.1) by roughly **115 mm** tall, plus
bleed and an overlap seam. That is a landscape sheet, so wrapping means placing this panel
on it and extending the orange field and the fruit border to fill the rest — say the word
and the script can emit that layout instead.

## Structure

Top-level groups are named for editing: `#bubbles`, `#top-fruit`, `#wordmark`, `#side-fruit`,
`#footer`. The scene is a single group clipped by `#clipScene`.

## Type

There are **no font dependencies** — every letter is a path. Type is drawn from a small
built-in stroke font (a skeleton path given a thick round cap/join), which is also what
produces the layered wordmark: the same skeleton stroked three times at decreasing widths
IS the cream/plum/orange outline stack.

The trade-off: these are geometric monoline letterforms, not the bubbly display face on the
mockup. If you own that typeface, set the wordmark in it and convert to outlines — replace
the `#wordmark` group and the `MANGO` line. Everything else can stay.

## Colours

Orange field `#F7B23F → #F0921F → #E07C15`, plum `#5B2A62`, cream `#FFF6E2`,
mango red `#E2521B`, greens `#1F5C33 / #2E7D3C / #5CA84C`. All are constants at the top of
the script.
